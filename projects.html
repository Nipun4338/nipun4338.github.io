Undergraduate thesis

Decentralized Election System

A blockchain-based election system for Bangladesh, built on Ethereum.

My B.Sc. thesis at AUST, supervised by Md. Khairul Hasan. It is a secure, transparent and tamper-proof voting system on Ethereum, designed for the context of Bangladesh.

Goals

  • Integrity: votes are recorded on a distributed ledger, so they can’t be altered after they are cast.
  • Anonymity: voters stay anonymous while the count stays publicly checkable.
  • Real-time verifiability: anyone can verify results as voting happens.

Joma Khoroch

A premium, smart personal finance tracker built with Next.js, PostgreSQL, and Material UI.

This application helps you track daily expenses, manage budgets, and gain deep insights into your financial health.

Recently Added Updates (v2.0)

We've recently overhauled the application with powerful new features and a modern aesthetic:

Smart Financial Intelligence

  • Velocity Budget Guide: A smart advisor that analyzes your spending speed and tells you if you are "On Track", during "Caution", or in a "Critical" budget state.
  • Spending Forecast: Predictive logic that calculates your expected month-end total based on current habits.
  • Category Analysis: Automatic grouping of expenses to show you exactly where your money is going (e.g., Food, Rent, Grocery).
  • Advanced Visualization: Upgraded charts to interactive Area Graphs with sleek gradients and dual-axis tracking for Income vs Expenses.

Premium UI/UX Modernization

  • Modern Design System: Completely rebuilt using Material UI with a glassmorphism theme, premium typography (Inter), and sleek gradients.
  • Responsive Navigation: Added a sticky, blurred header with direct access to your Dashboard and Insights.
  • Safety Checks: Integrated confirmation dialogs for deleting entries to prevent accidental data loss.
  • Precision Formatting: Standardized all currency to the Bangladesh standard (Taka symbol ৳) with Indian digit grouping and 100% accurate 2-decimal math.

Security Enhancements

  • Bcrypt Authentication: Switched to secure password hashing for all user accounts.
  • Improved Database Setup: Updated setup.sql with pre-hashed default credentials for immediate secure login.

Tech Stack

  • Frontend: Next.js, Material UI, Chart.js
  • Backend: Next.js API Routes, NextAuth.js
  • Database: PostgreSQL
  • Calculations: Native JavaScript Number precision with en-IN locale formatting.

Beyond Earth

An immersive, real-time space exploration dashboard built with React.

Beyond Earth provides users with a stunning window into the cosmos, featuring live data from NASA, upcoming rocket launches, space news, and interactive solar system visualizations.

Dynamic Space Facts

  • Daily Discoveries: Fetches the "Astronomy Picture of the Day" (APOD) directly from NASA.
  • Asteroid Watch: Real-time tracking of Near-Earth Objects (NEOs) passing by our planet.
  • Curated Trivia: A rotating collection of mind-blowing space facts.

Launch Center

  • Upcoming Launches: Live countdowns and details for the next 10 scheduled rocket launches worldwide.
  • Mission History: Archive of recent successful missions with video links and manifest details.
  • Data Source: Powered by The Space Devs API.

Space News Feed

  • Stay updated with the latest headlines from Spaceflight News API.
  • Read full articles on recent discoveries, commercial spaceflight, and astronomy.

Solar System Insights

  • Interactive cards displaying real-time known counts of planets, moons, comets, and asteroids.
  • Detailed "Planet Cards" with physical characteristics (mass, volume, gravity).
  • Age Calculator: Calculate your age on different planets!

Mars Rover Gallery

  • View high-definition images from the Curiosity rover.
  • Interactive modal for detailed photo inspection.

UI/UX Highlights

  • Immersive Design: Deep space theme with a custom starry background and nebula effects.
  • Glassmorphism: Modern, frosted-glass distinct headers and cards.
  • Interactive Elements: Hover-responsive cards, animated counters, and custom "Sci-Fi" typography.

Image Encrypter

Advanced Steganography and Data Protection Tool.

This tool focuses on securing visual data by transforming standard images into encrypted, unreadable formats. Using advanced mathematical modeling, it ensures that your sensitive images can be safely stored or transmitted without risk of unauthorized viewing.

Key Features

  • Dual-Layer Encryption: Protects data via both mathematical reshaping and character-based substitution.
  • Lossless Decryption: Guarantees the original image is restored pixel-perfectly with the correct key.
  • CSV Storage: Converts complex image data into portable, encrypted CSV files.
  • Format Conversion: Automatically optimizes images to PNG for consistent processing.
