Undergraduate thesis

Decentralized Election System

A blockchain-based election system for Bangladesh, built on Ethereum.

My B.Sc. thesis at AUST, supervised by Md. Khairul Hasan. It is a secure, transparent and tamper-proof voting system on Ethereum, designed for the context of Bangladesh.

Goals

  • Integrity: votes are recorded on a distributed ledger, so they can’t be altered after they are cast.
  • Anonymity: voters stay anonymous while the count stays publicly checkable.
  • Real-time verifiability: anyone can verify results as voting happens.

Blockchain dApp

CrowdCoin

Crowdfunding on Ethereum where contributors control how money is spent.

A factory contract deploys one Campaign contract per project. Anyone can contribute above a minimum, and contributors become approvers.

How it works

  • Spending requests: the campaign manager proposes a payment (description, amount, recipient).
  • Voting: each contributor can approve a request once.
  • Majority rule: a request can only be finalised, and the money sent, once more than half of the contributors approve it.
  • Tested: contract behaviour is covered by Mocha tests against a local Ganache chain.

It was deployed to the Rinkeby test network, which has since been shut down, so the live demo no longer works.

Bangladesh Cricket Results Analysis

Match results before and after Covid-19, and win prediction with machine learning.

An analysis of the Bangladesh national cricket team’s match results and how they changed after the Covid-19 period. The repository includes the dataset, the notebook, a written report and documentation.

Method

  • Prepared and encoded the match dataset with pandas.
  • Trained and compared five classifiers for win prediction: logistic regression, naive Bayes, k-nearest neighbours, support vector machine and random forest.
  • Evaluated each model with accuracy and a confusion matrix (the image shows the random forest’s).

Strider

A Strava-style GPS activity tracker with spatial segment matching.

An npm-workspaces monorepo with three parts: a shared TypeScript package of pure maths (Haversine distance, elevation, training load, the Banister performance model, a segment matcher), an Express + PostGIS API, and an Expo / React Native app that records GPS in the background and shows a live map.

Highlights

  • Segment matching in SQL: each track is one LineStringZM geometry with the timestamp in the M dimension, so finding segment efforts is an index-backed spatial query (ST_DWithin, ST_LineLocatePoint, ST_LineSubstring) and elapsed time is read straight from the M values.
  • Training analytics: daily fitness, fatigue and form (CTL / ATL / TSB) from the Banister model, plus goals with progress computed in SQL.
  • Server-side truth: the API derives distance, elevation and load from the raw track instead of trusting client totals.
  • Key-free maps: MapLibre GL in a WebView with OpenFreeMap tiles, so the app runs in Expo Go with no API keys.
  • Shared code: the same TypeScript maths runs on the phone and the server.

pdf2kindle

Turn Bengali, English or mixed PDFs into reflowable EPUBs for Kindle.

Runs entirely on your own machine, with no accounts or API keys, so books never leave it. It is built to handle Bengali books, which most converters get wrong.

Highlights

  • Digital PDFs: rebuilds paragraphs, joins end-of-line hyphens and removes running headers, footers and page numbers.
  • Legacy Bengali: remaps pre-Unicode Bijoy / SutonnyMJ text to Unicode.
  • Scanned or broken PDFs: OCR with Tesseract (Bengali + English).
  • Never garbled: pages that can’t be reflowed reliably (tables, multi-column layouts, maths, low-confidence OCR) are kept as images.
  • Kindle-ready: EPUB 3 with NCX, an editable table of contents, embedded Noto Serif Bengali, chapter footnotes, and compression to stay under Send-to-Kindle’s 50 MB limit.
  • Easy to run: one-click scripts, a Docker image and CI.
